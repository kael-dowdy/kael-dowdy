# Kael Dowdy

Senior Business Intelligence and Data Analytics Consultant

I build practical data solutions using SQL Server, Power BI, DAX, and Power Query M. My work spans database design and development, data transformation, semantic modeling, reporting, and analytics.

I own Maverick DataWorks LLC, my independent consulting business. This GitHub profile is where I share reusable code and explain approaches that other data professionals can adapt to their own work.

## What I share
- SQL scripts and reusable query patterns.
- Power Query M functions and transformations.
- DAX calculations and modeling examples as they are added.
- Documentation explaining purpose, dependencies, assumptions, and usage.

## Toolkit collections
My collections are being organized by technology and by the problem each example solves. Public examples will be added incrementally.

- power-query-toolkit: Power Query M functions, queries, and transformations.
- sql-toolkit: SQL scripts and database utilities, as published.
- dax-toolkit: DAX calculations and examples, as published.

## How I document examples
My goal is to explain what each example does, what it expects, how to use it, and where its assumptions matter. Where applicable, examples identify required queries, model relationships, locale settings, and platform-specific behavior.
